# 一句话总结

Summarize-Explain-Predict (SEP) 框架，用 self-reflective LLM 生成可解释的股票预测。CCF A 中非常重要的 LLM 股票预测论文。

# 研究任务

# 方法

- Summarize-Explain-Predict framework
- Self-reflective LLM 生成可解释预测

# 和 FinLeakAudit 的区别

- SEP 做 explainable prediction（可解释预测）
- FinLeakAudit 做 evidence leakage audit + revision（核查证据可靠性）
- SEP 不检查证据时间泄漏
