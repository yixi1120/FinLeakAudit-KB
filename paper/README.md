# Paper Build

This directory contains a workshop-neutral, anonymized two-column draft. It is not
yet formatted for a specific venue.

Build from this directory with:

```bash
make
```

The draft intentionally keeps the authors and repository URL anonymous. Replace the
article class with the selected venue template and confirm author order and
contributions before submission.

Current evidence boundary:

- The controlled and 10-event natural replay results are complete.
- The 79-pair controlled attribution gold set is complete.
- The frozen 82-pair natural semantic hard set is not yet labeled and is not used for
  paper claims.
- The current study supports a controlled auditability claim, not leakage prevalence
  or forecasting-performance superiority.
